# Nox Pomodoro

تطبيق لإدارة جلسات التركيز والاستراحات بطريقة Pomodoro، مع قائمة مهام تحفظ بياناتها محليًا في المتصفح.

## المميزات

- مؤقّت لجلسات العمل والاستراحة القصيرة والطويلة.
- انتقال تلقائي بين جلسات العمل والاستراحات عند انتهاء المؤقّت.
- إعداد مدد الجلسات وعدد جلسات العمل قبل الاستراحة الطويلة من زر الترس.
- حفظ إعدادات المؤقّت وحالته في `localStorage`، واستعادة العدّ التنازلي بعد إعادة تحميل الصفحة.
- إنشاء المهام وربط كل مهمة بعدد جلسات عمل وحذفها.
- تحديد عدد جلسات العمل المطلوبة لكل مهمة؛ وكل جلسة مكتملة تزيد تقدّم المهمة تلقائيًا.
- عرض تقدّم المهام وعدد الجلسات والوقت المتوقع لإكمال القائمة حسب مدة جلسة العمل.
- قبول عمليات حسابية في إعداد مدة الجلسة، مثل `45 * 0.33`، مع تقريب الناتج لأعلى إلى الدقيقة التالية.
- عكس ألوان الواجهة أثناء تشغيل المؤقّت باستخدام متغيرات CSS.
- إشعار نجاح متحرك عند اكتمال جلسة العمل ومهمتها.
- حفظ قائمة المهام في `localStorage` تحت المفتاح `Items` وعرض عددها.
- قسم `Source` لربط رابط YouTube وملاحظات وملف PDF بكل مهمة.
- حفظ روابط الفيديو والملاحظات محليًا، وتخزين ملفات PDF في `IndexedDB` لمعاينتها داخل التطبيق دون رفعها إلى خادم.

## المتطلبات

- Node.js و npm.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح عنوان التطوير الذي يعرضه Vite في الطرفية.

## أوامر المشروع

| الأمر | الاستخدام |
| --- | --- |
| `npm run dev` | تشغيل خادم التطوير |
| `npm run build` | إنشاء نسخة الإنتاج داخل `dist/` |
| `npm run preview` | معاينة نسخة الإنتاج محليًا |
| `npm run lint` | فحص ملفات المشروع باستخدام ESLint |

## التخزين المحلي

يخزن التطبيق البيانات على نفس المتصفح والجهاز باستخدام `localStorage`:

- `npomodoro.timer`: جلسة المؤقّت الحالية، الوقت المتبقي، مدد الجلسات، وإعداد عدد جلسات العمل قبل الاستراحة الطويلة.
- `Items`: قائمة المهام وعدد الجلسات المطلوبة والمكتملة لكل مهمة.
- `npomodoro.taskSources`: روابط YouTube وملاحظات المهام.

تُخزّن ملفات PDF محليًا في `IndexedDB`. لا تُرسل ملفات PDF أو الملاحظات أو روابط المصادر إلى خادم التطبيق. تشغيل فيديو YouTube المضمّن يتطلب اتصالًا بالإنترنت ويتصل بخدمات YouTube. البيانات المحلية لا تتم مزامنتها بين الأجهزة أو المتصفحات، وقد تُحذف عند مسح بيانات الموقع من المتصفح.
